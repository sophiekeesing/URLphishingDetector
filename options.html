🛡️ URL Shield settings

URL Shield works out of the box using a public DNS threat blocklist (Quad9) plus local heuristics. Adding a free Google Safe Browsing API key turns on the same phishing/malware list that Chrome itself uses.

  1. Open the Safe Browsing API page in Google Cloud Console and click Enable.
  2. Go to APIs & Services → Credentials and create an API key.
  3. Paste the key below and save.

The key is stored with chrome.storage.sync and is sent only to safebrowsing.googleapis.com.
